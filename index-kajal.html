Question 1 · Remembering

List four primary characteristics of a modern digital computer and identify the key hardware technology associated with each of the five generations of computers.

Four characteristics of a modern digital computer

  1. Speed: A computer performs millions or billions of operations in a very short time.
  2. Accuracy: It produces accurate results when the data and instructions provided are correct.
  3. Storage capacity: It can store large amounts of data and retrieve it whenever required.
  4. Diligence and consistency: It can repeat tasks for long periods without becoming tired or losing concentration.

Five generations of computers

GenerationMain hardware technologyGeneral features / examples
First (approx. 1940s–1950s)Vacuum tubesVery large, expensive, heat-producing machines; examples include ENIAC and UNIVAC I.
Second (approx. 1950s–1960s)TransistorsSmaller, faster, more reliable, and more energy-efficient than vacuum-tube computers.
Third (approx. 1960s–1970s)Integrated circuits (ICs)Many electronic components were placed on a chip, improving reliability and reducing size.
Fourth (from 1970s)Microprocessors using VLSI technologyPersonal computers and compact systems became widely available.
Fifth (modern and developing)ULSI, parallel processing, and AI-oriented technologiesEmphasis on artificial intelligence, natural-language processing, and advanced computing.

The dates of generations are approximate and can vary between textbooks.

Question 2 · Understanding

Explain the flow of data, instructions, and control signals within the functional block diagram of a computer, detailing the interaction between the CPU, memory unit, and I/O interface.

A computer system mainly consists of an input unit, a central processing unit (CPU), a memory unit, and an output unit. These parts communicate through data, address, and control buses.

Input devices → Input interface → CPU ↔ Main memory │ Data / Address / Control buses │ CPU → Output interface → Output devices

Working of the blocks

  1. Input unit: Devices such as a keyboard or scanner convert user input into a form the computer can process. The I/O interface transfers the data to the system.
  2. Memory unit: RAM temporarily stores the program instructions, input data, and intermediate results. Secondary storage keeps data for long-term use.
  3. Control unit (CU): The CU fetches instructions from memory, decodes them, and sends control signals to coordinate the ALU, memory, and I/O devices.
  4. Arithmetic Logic Unit (ALU): It performs arithmetic calculations and logical comparisons required by instructions.
  5. Registers: Small, fast storage locations inside the CPU hold instructions, addresses, and temporary data while processing.
  6. Output unit: After processing, results are sent through an output interface to a monitor, printer, speaker, or other device.

Example: When a user types two numbers and requests addition, the input interface sends the numbers to memory/CPU. The CU coordinates the operation, the ALU adds the numbers, and the result is sent to the display.

Question 3 · Applying

Demonstrate how optical data scanning devices (e.g., barcode/OMR scanners) and electronic card readers (e.g., RFID/smart card readers) can be deployed in a campus environment to automate student attendance and library checkouts.

A campus can combine scanning and card-reading systems with a student information database to reduce manual entry, speed up routine tasks, and improve record accuracy.

1. Attendance automation

  • Each student receives an ID card containing a barcode, RFID tag, or smart-chip identifier.
  • At the classroom entrance, a reader scans the card or detects it when it is tapped near the reader.
  • The system verifies the student ID and records the date, time, class, and attendance status in the campus database.
  • Teachers can review attendance reports and identify missing records. A duplicate scan can be flagged to prevent repeated entries.

2. Library checkout automation

  • Each book has a barcode or RFID tag linked to its catalogue record.
  • The librarian scans the student's ID and then scans the book barcode, or uses an RFID reader to identify tagged books.
  • The library system checks whether the student can borrow the item and records the loan date and due date.
  • At return, the book is scanned again, the loan record is updated, and any overdue status can be calculated automatically.
TechnologyHow it reads dataUseful campus application
Barcode scannerReads printed bars using lightAttendance IDs and library books
OMR (Optical Mark Recognition)Detects filled marks on specially designed formsExamination answer sheets and surveys
RFID readerUses radio waves to read a nearby tagQuick attendance and bulk library inventory
Smart-card readerReads data from a card chip, often by contact or near-field communicationSecure campus ID and access systems

Precautions: The campus should protect student data, restrict database access, provide a manual correction process, and keep a backup method for device or network failure.

Question 5 · Analyzing

Mouse and trackball devices are general-purpose pointing devices. A graphics tablet or digitizer is designed to capture pen movement and often pressure, tilt, or other drawing information.

Question 6 · Evaluating

Assess whether a drum/flatbed plotter or an ultra-high-definition monitor and large-format printer combination is superior for producing civil engineering blueprints, based on line resolution, scalability, and long-term production costs.

For most modern civil engineering offices, an ultra-high-definition monitor paired with a professional large-format printer is the more practical solution. A traditional plotter can still be useful in specialist environments, but the decision depends on print requirements, workload, and available budget.

CriterionDrum / flatbed plotterUHD monitor + large-format printer
Line resolutionTraditional pen plotters can draw accurate vector lines; output quality depends on pen, mechanics, and medium.A UHD display gives detailed on-screen review; the printer's resolution, ink, and paper determine printed line quality.
ScalabilityMay be limited by physical machine size and drawing setup.Digital drawings can be resized and printed in standard engineering sheet sizes, subject to scale and printer capacity.
WorkflowCan require special setup and may be slower for complex filled areas or colour graphics.Supports CAD review, revisions, digital sharing, and printing from common design software.
Initial costSpecialized plotters can have high purchase and maintenance costs.A UHD monitor and large-format printer can be acquired separately and upgraded as needs change.
Long-term costsDepend on parts, servicing, pens or consumables, and availability of support.Depend on ink/toner, paper, printhead maintenance, electricity, and service costs.

Recommendation

The UHD monitor and large-format printer combination is generally superior because it supports modern CAD workflows, easy revisions, digital collaboration, and flexible sheet sizes. For dependable blueprint production, select a printer that supports the required paper sizes, accurate scale, fine line detail, and archival media. Test a calibration print before issuing final drawings.

The choice should be based on actual total cost of ownership and print specifications; a UHD monitor improves viewing, but it does not itself determine the resolution of the printed blueprint.

Question 7 · Evaluating

Critique the operational reliability and security vulnerabilities of vision-input devices (facial recognition) compared to voice recognition devices when deployed as primary biometric authentication tools in high-ambient-noise, publicly exposed environments.

Facial recognition and voice recognition can both support biometric authentication, but neither should be treated as completely reliable or secure in every environment. In a noisy, public location, facial recognition is often more practical than voice recognition, although lighting, camera position, privacy, and spoofing risks remain important.

FactorFacial recognitionVoice recognition
Environmental reliabilityCan work in noise, but performance may fall with poor lighting, masks, occlusion, camera angle, or crowded backgrounds.Ambient noise, reverberation, distance, illness, and microphone quality can reduce accuracy.
Security risksMay be attacked with photographs, video, masks, or other presentation attacks if liveness detection is weak.May be attacked with recordings, synthetic voices, replay attacks, or imitation if anti-spoofing is weak.
PrivacyCaptures identifiable facial data, sometimes from people nearby who did not intend to authenticate.Captures voice data and may inadvertently record nearby conversations.
AccessibilityMay be difficult for some users due to camera placement, appearance changes, or visual impairments in the interface.May be unsuitable for people with speech differences or in places where speaking aloud is uncomfortable.
Practicality in noisy public spacesUsually more practical when lighting and camera placement are controlled.Usually less reliable when noise is high, unless a suitable microphone and noise processing are used.

Security recommendations

  • Use liveness detection and presentation-attack detection, and test systems against realistic spoofing attempts.
  • Protect biometric templates with encryption, strict access controls, limited retention, and a clear deletion policy.
  • Use a second factor, such as a secure card or PIN, for sensitive access rather than relying on one biometric alone.
  • Provide a non-biometric alternative and a process for failed matches.
  • Test false acceptance and false rejection rates across different users and real operating conditions.

Conclusion: Facial recognition is generally the more suitable of the two for a high-noise public environment, but it still has privacy and spoofing weaknesses. A layered authentication system with a secure backup is safer than either biometric method used alone.

Question 8 · Creating

Design an accessible, hands-free computer workstation tailored for a visually impaired user. Propose a coherent integration of non-visual input devices with specialized output devices.

The workstation should let a visually impaired user operate a computer without depending on a visual display. The design combines speech-based input, keyboard alternatives, screen-reading software, refreshable Braille, and accessible physical controls.

Proposed workstation components

  1. Computer and accessible operating system: A reliable computer with built-in accessibility settings, keyboard navigation, and support for assistive technology.
  2. Voice recognition microphone/headset: A noise-cancelling headset microphone lets the user dictate text, open applications, and issue commands. Push-to-talk or a clear wake command can reduce accidental activation.
  3. Screen reader: Software such as NVDA or another compatible screen reader announces menus, buttons, text, alerts, and navigation focus through speech.
  4. Text-to-speech output: A good-quality headset or speaker provides clear spoken feedback. A headset can improve privacy in shared rooms.
  5. Refreshable Braille display: A Braille display converts selected on-screen text into tactile Braille cells, allowing quiet reading and accurate editing.
  6. Accessible keyboard: A standard keyboard with tactile key markers, a high-contrast layout, or a Braille-labelled keyboard provides a reliable alternative when speech input is inaccurate.
  7. Accessible scanner and OCR: A document scanner or phone camera with optical character recognition converts printed pages into text that the screen reader can read aloud.

How the system works together

User speaks → Microphone / speech recognition → Computer application ↓ User receives feedback ← Screen reader / text-to-speech ← Screen content ↖ Refreshable Braille display (tactile text) Optional backup: tactile keyboard + keyboard shortcuts

Example workflow

The user says a command to open a document, dictates a paragraph, and uses keyboard shortcuts or voice commands to edit it. The screen reader announces the current heading and cursor position. The user checks exact spelling or punctuation on the Braille display, then saves the file using a spoken command or keyboard shortcut.

Accessibility, safety, and maintenance

  • Keep frequently used controls within easy reach and use tactile labels for ports and buttons.
  • Offer both voice and physical input so the user can continue working if speech recognition fails.
  • Use headphones in shared spaces and obtain consent before recording or processing voice data.
  • Provide training, software updates, backups, and a support plan for assistive devices.
  • Test the complete workflow with the intended user and adapt speech rate, voice, Braille settings, and keyboard layout to their preferences.

Conclusion: A combination of speech input, keyboard access, screen-reader speech, and refreshable Braille offers flexible hands-free and non-visual access. Multiple input and output options make the workstation more reliable and user-centred.
